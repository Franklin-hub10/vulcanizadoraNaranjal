# Roadmap de madurez

Este roadmap define etapas, no fechas comprometidas.

## VN-00 — Gobernanza inicial

**Objetivo:** establecer el marco antes de modelar el negocio.

Estado: **EN PROGRESO / núcleo creado**

Incluye:

- fuente de verdad;
- actores;
- reglas duras;
- routing;
- arquitectura base;
- política de cambios;
- ciclo de vida del conocimiento;
- auditoría;
- histórico.

## VN-01 — Descubrimiento con Joel

**Objetivo:** aprender el negocio real.

El organizador capturará progresivamente:

- funcionamiento general;
- servicios;
- actividades;
- precios;
- costos;
- gastos;
- recursos;
- personas y responsabilidades relevantes;
- formas de registro actuales;
- necesidades de consulta;
- eventos importantes de la operación.

No se presupone la existencia de ninguno de estos elementos concretos.

## VN-02 — Modelo base del negocio

**Objetivo:** transformar el levantamiento confirmado en fuentes canónicas.

Resultados esperados:

- mapa real del negocio;
- entidades y relaciones;
- catálogo real de conceptos;
- reglas de negocio;
- definiciones financieras;
- modelo de registro;
- pendientes de información.

## VN-03 — Operación persistente

**Objetivo:** usar el organizador en el día a día.

El sistema deberá permitir incorporar cambios y eventos sin perder consistencia ni histórico.

## VN-04 — Indicadores y análisis

**Objetivo:** responder preguntas de desempeño con definiciones reproducibles.

Los KPI se crean solo cuando:

- existe una definición;
- existen datos suficientes;
- se conoce el periodo;
- se conoce la fuente;
- se conoce qué significa el resultado.

## VN-05 — Escenarios, pilotos y proyecciones

**Objetivo:** utilizar el histórico para evaluar alternativas.

Se podrán documentar:

- pilotos;
- hipótesis;
- escenarios;
- inversión;
- costos;
- resultados esperados y reales;
- proyecciones.

Una proyección nunca se presenta como resultado observado.

## Regla de avance

Una etapa puede comenzar parcialmente cuando exista suficiente información, pero ningún documento debe aparentar un nivel de madurez que el negocio todavía no tiene.
