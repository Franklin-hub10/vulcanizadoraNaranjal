# Gobernanza

Este directorio contiene las **reglas duras** que determinan cómo debe comportarse el organizador y cómo se estructura el conocimiento de Vulcanizadora Naranjal.

## Documentos

- `RULES.md` — reglas obligatorias.
- `ACTORS_AND_ACCESS.md` — alcance de Franklin y Joel.
- `ARCHITECTURE.md` — arquitectura del conocimiento.
- `CHANGE_POLICY.md` — cómo se modifican estructura y reglas.
- `KNOWLEDGE_LIFECYCLE.md` — cómo nace, valida, actualiza y conserva la información.
- `USER_MANUAL.md` — guía de interacción.
- `PENDING_DECISIONS.md` — decisiones estructurales aún no aprobadas.
- `VERSION.md` — versión vigente de la gobernanza.

## Jerarquía

Ante conflicto entre un dato operativo y una regla de gobernanza, prevalece la gobernanza hasta que Franklin apruebe su cambio.

La gobernanza no debe convertirse en un contenedor de datos diarios del negocio.
