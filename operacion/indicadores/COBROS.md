# Índice operativo de cobros

## Propósito

Mantener una base trazable de sesiones de trabajo efectivamente cobradas para futuras consultas e indicadores.

## Alcance actual

Este archivo no define todavía un tablero financiero completo ni declara iniciada la fase VN-04.

Solo indexa cobros con confirmación explícita de Joel y referencia al registro canónico de `operacion/cobros/`.

## Regla de inclusión

Un registro entra en este índice únicamente si su estado canónico es `cobrado`.

Las proformas pendientes o simplemente confirmadas no cuentan como ingreso cobrado.

## Cobros indexados

Aún no existen cobros confirmados registrados bajo esta política.
