# Índice de proformas realizadas

## Propósito

Indexar únicamente proformas que Joel haya confirmado como correctas conforme a `governance/PROFORMAS_Y_COBROS.md`.

## Regla

- Un cálculo presentado pero aún no confirmado no se registra aquí.
- Cada proforma confirmada debe tener un archivo propio en esta carpeta.
- Formato de ID: `PF-YYYYMMDD-NNN`.
- Estado permitido en este índice: `proforma_confirmada` o, si posteriormente fue cobrada, referencia al cobro relacionado.

## Registros

Aún no existen proformas confirmadas registradas bajo esta política.
